# CSV 3D Viewer

一个在浏览器中将 CSV 文件渲染为可交互 3D 场景的 HTML 工具，帮助需要快速查看数值型数据空间分布的开发者、学生和数据分析人员。

## 项目状态

开发中。当前处于[设计阶段/基础功能开发阶段]，CSV 解析、列映射和 3D 渲染功能正在完善，尚不提供稳定安装包。

> 如果已有可运行版本，请改为如实描述，例如：当前已实现 CSV 读取和基础 3D 散点渲染，坐标轴和交互仍在开发中。

## 安装或获取

当前为设计/开发阶段，暂无稳定安装包。

后续计划通过浏览器直接打开 HTML 页面使用。开发完成后，获取方式为：

1. 克隆仓库到本地；
2. 在项目目录启动本地 HTTP 服务器，例如 `python -m http.server`；
3. 浏览器访问本地服务器地址。

> 如果当前已有 `index.html` 且已验证可运行，请把上面的计划改为你亲自验证过的真实命令。

## 使用说明

当前版本尚未提供可执行的稳定操作步骤。设计中的最小操作流程为：

1. 选择一个 CSV 文件；
2. 选择用于 X、Y、Z 轴的数值列；
3. 在 3D 场景中旋转、缩放查看数据分布。

> 只有已经实现并验证后，才可把以上步骤写成“使用步骤”，否则保留“设计中”说明。

## 项目结构与依赖

计划结构：

- `index.html`：页面入口；
- `main.js`：CSV 读取与 3D 渲染逻辑；
- `styles.css`：页面样式；
- `README.md`：项目说明；
- `LICENSE`：Apache-2.0 许可证；
- `compliance-analysis.md`：许可证选择分析。
